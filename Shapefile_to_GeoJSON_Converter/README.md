# Shapefile to GeoJSON Converter with Style

A QGIS plugin for converting multiple opened Shapefile layers into GeoJSON format with WebGIS-ready outputs.

## Features

- Batch export multiple layers
- Export selected layers only
- Output folder selection
- Unicode/Marathi filename support
- GeoJSON export
- Optional QML style export
- WebGIS workflow support
- Simple and beginner-friendly UI

## Use Cases

- Web mapping
- Leaflet/OpenLayers workflows
- GIS data sharing
- GeoJSON conversion pipelines
- Smart city and planning projects

## Compatible With

- QGIS 3.22+
- Windows/Linux
